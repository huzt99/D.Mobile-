# فاحص الأجهزة (Device Doctor)

مشروع واحد يطلّع ملفين:
- **DeviceDoctor.exe** للكمبيوتر (ويندوز): يفحص الكمبيوتر نفسه، وكذلك الموبايل المتصل بكابل USB.
- **app-debug.apk** للموبايل (أندرويد): يفحص نفس الموبايل (بطارية، حرارة، حساسات، لمس، شاشة، سماعة، مايك، كاميرات، اهتزاز).

## 1) البناء (GitHub Actions)
1. سوّي repo جديد على GitHub (مثلاً `DeviceDoctor`) وارفع محتوى هذا المجلد كما هو (لازم يظهر `.github/workflows`).
2. افتح تبويب **Actions** ← شغّل **Build EXE** و **Build APK** (أو يشتغلون تلقائيًا مع كل push).
3. بعد ما ينتهون: ادخل على كل Run ← **Artifacts** ← نزّل `DeviceDoctor-exe` و `DeviceDoctor-apk`.

> أول بناء للـAPK ممكن يطلع فيه خطأ بسيط (إصدارات Gradle مثلاً). إذا صار، انسخ لي سطور الخطأ من الـlog وأصلحه.

## 2) استخدام EXE
- شغّله بصلاحية مسؤول (يطلبها تلقائيًا) حتى يقرأ SMART والحرارة.
- **🖥 فحص الكمبيوتر:** أقراص، SMART، مساحة، رام، معالج وحرارة، بطارية اللابتوب، أجهزة معطلة، كرت الشاشة، أخطاء العتاد، الشاشة الزرقاء، الشبكة.
- **📱 فحص الموبايل:** وصّل الموبايل بكابل بيانات، فعّل خيارات المطور ← USB debugging، ووافق على نافذة السماح.
- **💾 حفظ التقرير** يطلع ملف HTML فيه كل شي مع الحلول المقترحة.
- قد يحذّر مضاد الفيروسات من أي exe جديد غير موقّع؛ هذا إنذار كاذب شائع مع PyInstaller.

## 3) استخدام APK
ثبّته على الموبايل (اسمح بالتثبيت من مصدر غير معروف) ← **فحص سريع** ← **اختبارات يدوية** ← **التقرير**.

## 4) الفحص عن بعد عبر الواي فاي
- **الكمبيوتر:** شغّل EXE واضغط **📡 وضع الاستقبال** ← يظهر IP و PIN (اسمح لـFirewall لو سأل).
- **موبايل ثاني:** في التطبيق تبويب **جهاز آخر** ← **تشغيل وضع الاستقبال** ← يظهر IP و PIN.
- **من تطبيق الموبايل الفاحص:** تبويب **جهاز آخر** ← اكتب IP و PIN ← **افحص الجهاز** (يعرف لحاله إذا كمبيوتر أو موبايل).
- الجهازين لازم على نفس الواي فاي. خلّ التطبيق مفتوح على الجهاز المستقبِل.

## 5) مساعد الأعطال + فلاشة الفحص
- في تطبيق الموبايل تبويب **مساعد الأعطال**: أسئلة بسيطة تعطيك السبب الأقرب، وخانة لأكواد الشاشة الزرقاء.
- للجهاز اللي ما ينهض: استعمل **DeviceDoctor-USB** (دليل الخطوات في `README-USB-AR.txt`): تقلع من الفلاشة ويحفظ التقرير عليها.

## حدود لازم تعرفها
- البرنامج يكشف الأعطال من القراءات والأخطاء؛ ما يشوف تلف الدوائر أو اللوحة الأم مباشرة.
- بعض الموبايلات ما تعرض سعة/دورات البطارية بدون Root.
- iPhone غير مدعوم في هذي النسخة.

## فحص جهاز آخر من تطبيق الموبايل (طريقتين)
- **📶 شبكة**: واي فاي، أو كيبل USB مع تفعيل «مشاركة الإنترنت عبر USB» على الجهاز الثاني. الجهاز الثاني يشغّل «وضع الاستقبال»، وهذا يبحث عنه تلقائيًا أو تكتب IP وPIN.
- **🔌 كيبل OTG (ADB)**: وصّل الجهاز الثاني بكيبل OTG وفعّل عليه «تصحيح USB» (ما يحتاج ينثبّت عليه التطبيق). وافق على رسالة السماح هنا وعلى الجهاز الثاني.
- كلا الطريقتين يفحص الجهاز الموصل: البطارية، الرام، التخزين، الهاردوير والسوفتوير، الحساسات، والكاميرات (ADB). اختبارات اللمس والصوت والكاميرا اليدوية تتم على الجهاز نفسه.
